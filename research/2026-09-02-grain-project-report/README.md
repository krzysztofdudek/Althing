# Grain's first project: the director's final report

**Question:** Did the first Grain project make a coding agent produce better diffs than it does with grep alone?

**Method:** Grain's director agent's end-of-project report, written the day the owner stopped the project, pulling together the audits, corpus runs, field tests, instruments and paired agent trials of 24 August to 2 September 2026.

**Status:** concluded

**Conclusion:** The engine was accurate but had no proven effect: paired trials changed 0 of 25 diffs, and the one documented effect came from a note Grain gave on its own before the agent wrote, not from an answer to a question.
