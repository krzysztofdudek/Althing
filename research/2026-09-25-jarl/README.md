# Jarl: improvements from two days of real use

**Question:** What did running a 231-issue release loop on Jarl show about the tool?

**Method:** A count over the 6.1.0 loop's whole record (issues, log, rulings, evidence and reviews) and scratch loops run against Jarl's code; findings verified by a sceptic.

**Status:** concluded

**Conclusion:** The record held, but the loop did not run the way Jarl models work: packages instead of single issues, few fresh reviews (17 of 221 approvals), and state kept in prose; the report proposes the commands and fields that would carry it.

## What is here

- [report.md](report.md): the verdict, the ranked proposals and the evidence
- [findings.json](findings.json): every verified finding
