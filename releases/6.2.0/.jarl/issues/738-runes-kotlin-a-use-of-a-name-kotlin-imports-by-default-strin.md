## What
Issue 732 gave classifyUse an answer that tells a use leaving the repository from one the readers could not follow, and taught Java its standard library (java., javax., jdk. imports and the bare names of java.lang). Kotlin has no such reading: the names Kotlin imports into every file (kotlin.*, kotlin.annotation.*, kotlin.collections.*, kotlin.comparisons.*, kotlin.io.*, kotlin.ranges.*, kotlin.sequences.*, kotlin.text.*, and on the JVM java.lang.* and kotlin.jvm.*) come back as unfollowed.

## Why
A consumer that reports every use it could not follow would flag String and listOf in every Kotlin file, the same noise 732 line 7 removed for Java.
