## Changelog
- in Python, maturin's `[tool.maturin] python-source`, the PDM backend's `[tool.pdm.build] package-dir` and Hatch's `sources` (`sources = ["lib"]`, or a mapping whose every member maps a prefix to `""`, read from the wheel target when it sets them and from `[tool.hatch.build]` otherwise, as hatchling reads them) name a source root too, so a mixed Rust and Python project with `python-source = "python"` has the absolute imports of its package give their edges where 1.1.0 answered them `outside`.
